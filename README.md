# DDOSerer Lite
Introducing the **Lite version** of **DDOSerer**! This version is optimized for performance and simplicity, making it a great choice for users who need a faster and more streamlined tool.
> [!NOTE]
> For a more feature-rich experience, check out the [full version of DDOSerer](https://github.com/Nekoobs/DDOSerer), which includes additional functionalities.
## What's Different?
- **Lightweight**: Optimized for all devices and platforms, ensuring fast performance.
- **No Debug Mode**: Designed for quicker loading without the debugging features.
- **HostId**: Allows for quicker form submissions.
- **Enhanced CAPTCHA Handling**: Improved CAPTCHA decoding capabilities.
## Installation
1. **Install Tampermonkey**:
   - [Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en)
   - [Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
   - [Safari](https://www.tampermonkey.net/index.php?browser=safari&locale=en)
2. **Add the UserScript**:
   - Open the Tampermonkey dashboard and create a new script.
   - Copy and paste the script content into the editor.
   - Save the script.
