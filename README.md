# DDOSerer Lite  
The **Lite version** is here!
- Designed to be lightweight and compatible with all devices and platforms.# What's Different?  
- No Debug Mode for quicker loading  
- HostId for faster submissions  
- Improved Captcha  
# Installation  
1. Install Tampermonkey:  
   - [Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en)  
   - [Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)  
   - [Safari](https://www.tampermonkey.net/index.php?browser=safari&locale=en)  
2. Add the UserScript:  
   - Open the Tampermonkey dashboard and create a new script.  
   - Copy and paste the script content into the editor.  
   - Save the script.
