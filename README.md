# DDOSerer Lite  
Introducing the **Lite version**!
# What's Different?
- Lightweight and compatible with all devices and platforms.
- No Debug Mode for faster loading.
- HostId for quicker submissions.
- Enhanced Captcha.
# Installation  
1. Install Tampermonkey:  
   - [Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en)  
   - [Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)  
   - [Safari](https://www.tampermonkey.net/index.php?browser=safari&locale=en)  
2. Add the UserScript:  
   - Go to the Tampermonkey dashboard and create a new script.  
   - Paste the script content into the editor.  
   - Save the script.
